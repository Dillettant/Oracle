# Oracle Commercial & Licensing Information

## Dual Licensing Model

Oracle uses a dual licensing model to support both open-source community development and commercial sustainability.

### Open Source License: AGPL-3.0

The core Oracle platform is licensed under the **GNU Affero General Public License v3.0 (AGPL-3.0)**.

**What this means:**
- Free to use, modify, and distribute
- Source code must remain open source
- Network use (SaaS) requires source disclosure
- Modifications must be shared under AGPL-3.0
- No warranty provided

**Ideal for:**
- Personal use and learning
- Academic research
- Open-source projects
- Self-hosted deployments (personal)
- Contributing to the project

### Commercial License

For organizations that cannot comply with AGPL-3.0 requirements, we offer commercial licensing.

**Commercial license includes:**
- Use without AGPL-3.0 obligations
- No requirement to disclose source code
- SaaS deployment rights
- Priority support
- Custom feature development (negotiable)

## Frequently Asked Questions

### Can I use Oracle for free?

Yes! The Community edition is free forever under AGPL-3.0. You can self-host it for personal use, learning, or as part of an open-source project.

### Do I need a commercial license for my startup?

It depends:
- If you're contributing changes back to open source: No
- If you're building a SaaS product on Oracle: Yes
- If you're using it internally and can comply with AGPL-3.0: No

### Can I modify Oracle for my own use?

Yes, under AGPL-3.0. However, if you distribute your modifications or provide them as a network service, you must make the source code available.

### What if I want to integrate Oracle into a proprietary product?

You'll need a commercial license. The AGPL-3.0 requires derivative works to be open-sourced.

### Is there a trial for paid plans?

Yes! All paid plans include a 14-day free trial. No credit card required for the trial.

### Can I switch between plans?

Yes. You can upgrade or downgrade at any time. Changes take effect at the next billing cycle.
