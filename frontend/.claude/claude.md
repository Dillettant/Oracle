# Claude Code Preferences - Oracle Frontend

## UI Direction
- Keep the oracle-gradient + glass-card language intact.
- Use Space Grotesk for display and IBM Plex Mono for accents.
- Prefer rounded, soft panels with bold uppercase labels.
- Maintain high-contrast text for readability.

## Component Patterns
- Use functional React components with hooks.
- Keep layout in pages, reuse UI blocks in components.
- Avoid introducing heavy UI libraries; stick with TailwindCSS.

## Styling Notes
- Keep spacing generous (4-8 scale).
- Use subtle shadows and glass effects sparingly.
- Use ember (#f36b3f) for primary action emphasis.

## API Usage
- Use services in src/services for network calls.
- Store tokens in Zustand and localStorage.
